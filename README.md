# Emoji Match

A 60-second iOS emoji connection puzzle. Connect exactly three matching emojis with a limited-length string, clear them, and refill the board.

## MVP
- 6 × 8 grid with 8 emoji types
- 5 tile-unit maximum connection length
- Exactly three matching tiles automatically clear
- 100 points per match, 60-second round
- Gravity, refill, and solvability checks

Implementation in Swift and SpriteKit. Work in progress.
